## Question

Write a program that asks the user for max points (an int) on a test, and then
asks for their score (a float --- they could get half points). Then print the
score as a percentage formatted to exactly 1 decimal place.

The output should look like:

```
What was the test out of? 34
What was your score? 22.5
Score: 66.2%
```

## Sample Solution

```python
out_of = int(input('What was the test out of? '))
score = float(input('What was your score? '))

percentage = 100 * (score / out_of)

print(f'Score: {percentage:.1f}%')
```

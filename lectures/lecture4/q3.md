## Question

A pizza costs $47 and 3 friends split the cost evenly between them. Print how
much each friend owes, rounded to the nearest cent.

The output should look like:

```
Each friend owes ?? dollars
```

Replace the `??` with the correct amount owed by each friend, and do the
calculations in your program.

## Sample Solution

```python
print('Each friend owes', round(47 / 3), 'dollars')
```

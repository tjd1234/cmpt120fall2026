## Question

Write a program that asks the user how many nickels and quarters they have, and
then prints the total value in dollars, formatted to exactly 2 decimal places.

The output should look like:

```
How many nickels do you have? 2
How many quarters do you have? 3
You have $0.85 dollars.
```

## Sample Solution

```python
nickels = int(input('How many nickels do you have? '))
quarters = int(input('How many quarters do you have? '))

total_cents = nickels * 5 + quarters * 25

# use an f-string to format the total in dollars to 2 decimal places
print(f'You have ${total_cents / 100:.2f} dollars.')
```

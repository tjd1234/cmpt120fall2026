# Writing Code with AI: Tic Tac Toe

In this activity, your task is to use AI to make a graphical and mouse-based
[Tic Tac Toe](https://en.wikipedia.org/wiki/Tic-tac-toe) game using Python.

You can use any AI you want, such as [ChatGPT](https://chatgpt.com) or
[Gemini](https://gemini.google.com). You do *not* need to use a paid AI service.

You should write English prompts to guide the AI to write the program. The
output should be plain Python that could run on anyone's computer if they have
Python installed with turtle graphics. Do not let the AI use any extra libraries
or frameworks.

Save your prompts, and submit them with your finished program. You *don't* need
to do it all in one big prompt. Try asking the AI to make the basic game, and
then add features one at a time with separate prompts.


## Required features

- graphical board and pieces

- click with mouse to place pieces

- human plays versus the computer, and can choose from at least three different
  opponents:
  - **Smart**: never loses, and always wins if possible
  - **Random**: always blocks the human from winning, and always wins if
    possible, but otherwise always chooses a random empty square
  - **Loopy**: tries as hard as it can to lose, i.e. it never makes a winning
    move (unless it's forced to), and it tries to set up the human to win

- automatically check for a winner or draw

- display the winner or draw

- ask the user if they want to play again

- keeps track of number of wins, losses, and ties

## Optional features

In addition to the basic requirements, please add at least three other good,
cool, or fun features you can think of. Some examples:

- give the game a logo

- when the human wins, make, for example, some animated fireworks

- make it look like you are playing against a character, e.g. here's an old TV
  commercial for [Tic Tac Toe against a
  chicken](https://www.youtube.com/watch?v=4q5je2fpXVQ)

- add an undo button that allows the human to undo their last move

- add more computer playing styles

- add options to play [alternative versions of Tic Tac
  Toe](https://en.wikipedia.org/wiki/Tic-tac-toe_variants), e.g.:

  - **Reverse Tic Tac Toe**: whoever gets three in a row first loses

  - **Three Piece Tic Tac Toe**: each play gets only three pieces, and from
    their fourth turn on when they place a piece their oldest piece is removed
    and placed as the piece
